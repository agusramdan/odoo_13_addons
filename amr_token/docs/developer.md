# `amr_token` — Panduan Developer

> Provenance upstream: source Odoo 13 [`addons_oidc` commit `6725f802acde636be0b25e2c140d15dccd37b0db`](https://github.com/agusramdan/addons_oidc/tree/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token). Uraian di bawah menjelaskan kontrak pada pin dan mencocokkannya dengan kode kandidat lokal; rujukan kandidat diberi label tersendiri. ## 3. Source mode dan private-key retrieval

`get_private_key()` mengambil nilai untuk `database`, PEM dari environment/config/system parameter, atau membaca file melalui path. `reference` memiliki arti berbeda menurut mode. Label `hsm` tersedia pada Selection, tetapi tidak ada cabang implementasi HSM: eksekusi jatuh ke `ValueError("Unsupported source: hsm")` ([retrieval upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/public_key.py#L82-L113), [retrieval kandidat](../models/public_key.py#L81-L112)).

Penting: metode `PublicKey.generate_token()` menggunakan `self.private_key` secara langsung dan tidak memanggil `get_private_key()`. Karena itu, keberadaan retrieval helper untuk environment/config/path tidak membuktikan mode tersebut dapat dipakai untuk signing. `hsm_key_id` juga tidak membuktikan koneksi HSM ([`generate_token` upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/public_key.py#L131-L140), [method kandidat](../models/public_key.py#L130-L139)).

## 4. JWKS dan route

- Controller mendeklarasikan `GET /.well-known/jwks.json` dengan `auth='public'`, `csrf=False`; route meneruskan ke `amr.token.helper.oidc_jwks()` ([route upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/controllers/main.py#L52-L60), [route kandidat](../controllers/main.py#L56-L59)).
- `oidc_jwks()` memanggil `amr.public.key` dengan `sudo()` dan membungkus hasil sebagai `{"keys": ...}` ([helper upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/helper.py#L263-L267), [helper kandidat](../models/helper.py#L187-L189)).
- `get_jwks()` mencari record `active=True` saja. Ia tidak memfilter `expires_at` atau `is_signing`. `is_signing=True` hanya menambahkan `use: "sig"`; field itu tidak menentukan keikutsertaan key. Source menambahkan `kid` dan `alg`; algoritma ES memakai `ECAlgorithm`, selebihnya memakai `RSAAlgorithm` ([serialisasi upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/public_key.py#L115-L129), [serialisasi kandidat](../models/public_key.py#L114-L128)).
- Discovery route `GET /.well-known/openid-configuration` juga dideklarasikan publik dan source membentuk `jwks_uri` relatif ke issuer ([controller upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/controllers/main.py#L52-L60), [discovery kandidat](../models/helper.py#L170-L185)). Ini pembacaan source, bukan bukti route berjalan pada server.

## 5. Signing, validation, dan batas key selection

`generate_token_asymmetric()` mencari record berdasarkan `algorithm` saja, tanpa filter `active`/`is_signing`, tanpa `kid`, dan tanpa `limit`; beberapa record dengan algoritma sama dapat membuat pemilihan ambigu. `validate_asymmetric()` mencari berdasarkan `algorithm` dan `kid`, tetapi tidak memfilter `active`. Jangan mengasumsikan ada pemilihan key deterministik atau lifecycle enforcement di luar kode yang tampak ([helper signing/validation upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/helper.py#L448-L469), [lookup validation upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/helper.py#L511-L523), [implementasi kandidat](../models/helper.py#L297-L366)).

Tidak ada unique constraint untuk `kid` atau validasi yang mengikat tipe key PEM dengan pilihan algoritma pada model. `expires_at` tersedia sebagai field, tetapi tidak ditegakkan oleh `get_jwks()`. Ini adalah perilaku/gap source, bukan rekomendasi untuk memakai konfigurasi yang berisiko.

## 6. Settings dan key generation

`res.config.settings` mendeklarasikan `amr_token_signature_type` (`secret`/`public_key`), secret algorithm HS256/384/512, public-key algorithm ES/RS/PS, parameter `amr_token.expires_in`, `amr_token.retention_in`, dan `amr_token_audience` dengan `config_parameter="database.uuid"`. Namun, helper `get_audience()` mendelegasikan pembacaan ke `amr.resource.helper`; jangan menganggap field settings tersebut sebagai nilai efektif tanpa memeriksa consumer/runtime. Helper memilih `secret_algorithm` atau `public_key_algorithm` berdasarkan `signature_type`; field `amr_token_algorithm` terpisah juga tidak boleh diasumsikan sebagai sumber pilihan efektif ([settings upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/res_config_settings.py#L6-L76), [helper selection upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/helper.py#L179-L217), [settings kandidat](../models/res_config_settings.py#L6-L76), [helper kandidat](../models/helper.py#L132-L163)).

`Create Key` pada settings memanggil `action_create_public_key`; helper membuat pasangan key dan record `amr.public.key`. Jalur ini menyerialisasi private key sebagai PKCS#8 PEM dengan `NoEncryption()` lalu menyimpannya pada field Text. Method model `action_generate_key()` berbeda: ia menulis key ke record yang sedang dibuka, tetapi form public-key kandidat tidak memiliki tombol aktif untuk method tersebut (header action contoh di XML dikomentari). Jangan gunakan salah satu jalur untuk key nyata/produksi sebelum ada desain dan clearance keamanan tersendiri ([button settings kandidat](../views/res_config_settings_views.xml#L33-L36), [aksi settings upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/res_config_settings.py#L75-L76), [helper upstream](https://github.com/agusramdan/addons_oidc/blob/6725f802acde636be0b25e2c140d15dccd37b0db/amr_token/models/helper.py#L99-L151), [method kandidat](../models/public_key.py#L141-L144), [form header kandidat](../views/public_key_views.xml#L11-L29)).

## 9. Batas aman dokumentasi/demo

- Jangan memasukkan private key, secret, JWT, token, credential, atau data pengguna nyata ke dokumentasi, test, demo, log, screenshot, maupun tiket.
- Kandidat repository menyertakan [`demo/public_key_demo.xml`](../demo/public_key_demo.xml), yang didaftarkan pada bagian `demo` manifest dan dimuat hanya bila instalasi mengaktifkan data demo. Record memakai public PEM sintetis, `active=False`, `is_signing=False`, dan tidak memasok `private_key`. Jangan aktifkan atau gunakan sebagai key nyata/produksi.
- Record aktif masuk ke kandidat JWKS menurut source walaupun `is_signing=False` atau `expires_at` telah lewat. Jangan menganggap expiry sebagai mekanisme pencabutan.
- Field HSM bukan dukungan HSM; source melempar `ValueError` untuk mode itu. Retrieval non-database juga tidak dibuktikan sebagai signing path.
- Deskripsi di panduan ini dicocokkan secara statis dengan source kandidat saat penyusunan; perubahan kode setelahnya memerlukan pengecekan ulang. Dokumentasi tidak menggantikan test, review Security, atau UAT.
