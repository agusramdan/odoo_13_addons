## Paket pilihan konkret untuk Owner — seluruhnya OPEN
- **D1 rekomendasi R:** tolak secara eksplisit positional yang ambigu sebelum provider/network, dengan exception dan pola pemanggilan yang tepat ditetapkan sebelum implementasi; migrasikan caller ke keyword. **Alternatif P:** pertahankan binding lama, termasuk headers kelima dan flag keenam, serta deteksi duplicate secara eksplisit. Keduanya melarang POST berubah diam-diam menjadi GET. Konsekuensi: V01–V03 memverifikasi hasil berbeda; tidak memilih daftar bentuk yang ditolak secara sepihak.
- **D2 rekomendasi R:** teruskan objek asli termasuk None/False/{} tanpa substitusi sebelum normalizer; normalizer boleh mengembalikan hasil kosong dan key headers dihilangkan. **Alternatif C:** konversi input tertentu menjadi `{}`; tentukan cakupan, identitas dan mutasi; C mengubah AU10 dan memerlukan acceptance eksplisit. V04 dan AU10 memiliki oracle berbeda.
- **D3 rekomendasi R:** method per-call dan stored keduanya falsy → error eksplisit sebelum provider/transport; tetapkan tipe, return, hook dan writer. **Alternatif G:** default GET secara eksplisit hanya jika bukan POST positional yang salah bind; tetapkan reporting/error equivalence. V05 harus mengukur outbound, hook dan error writer terpisah.
- **D4 rekomendasi R:** laporkan method efektif pasca-provider, fallback input saat preparation/provider belum menghasilkan context; definisikan absent dan exception hook. **Alternatif I:** laporkan input method asli pada direct; **alternatif B:** method efektif pra-provider. Perubahan semantik direct/U14 memerlukan persetujuan; V06/V10 memisahkan ketiga oracle.
- **D5 rekomendasi R:** whitelist berdasarkan entry point; tolak unknown sebelum provider/network, daftar path omitted/None, audience positional/keyword, url, raise_exception dan wrapper ditetapkan setelah inventaris. **Alternatif L:** pertahankan binding/forward/ignore lama secara eksplisit per entry point; **alternatif F:** forward unknown hanya setelah kontrak provider disetujui. V03/V09 perlu oracle per entry point, bukan satu asumsi semua wrapper.
